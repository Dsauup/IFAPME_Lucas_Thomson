Mes expériences

Voici mes expériences dans le domaine du développement.

Ces expériences ne figurent pas sur le CV car elles sont scolaires.

Ces expériences sont suceptibles d'être remplacées dût à mon incapacité de les référencer / documenter en profondeur.

Site web "Epi Doré"

Cette expérience consiste à créer un site web pour un projet scolaire.

J'ai utilisé HTML, CSS, PHP et JavaScript pour réaliser ce projet ainsi qu'une base de données SQL sur laquelle je gérais un panier, des comptes et des commandes.

L'hébergeur du site était à ce moment là alwaysdata et le site était destiné / à l'image d'une boulangerie en face de l'école.

à mon plus grand regret ce projet et les suivants ont été perdus à la suite de ma clé USB s'étant égarée.

Jeu vidéo python / pygame / orienté objet

Cette expérience consiste à créer un jeu vidéo en utilisant Python et pygame.

J'ai utilisé Python et pygame pour réaliser ce projet. Il consistait d'un mélange du jeu "Doom" et "Hatred" ou l'on doit tuer des vagues d'alien avec des armes trouvées sur le terrain.

Ce projet m'a beaucoup appris sur les langages cités ci dessus et le fonctionnement / techniques de la confection de jeux isométriques.

Urbex Gears

Ce projet et le dernier était un site web à theme libre non finit qui était un site de vente de matériel pour pratiquer l'exploration urbaine.

Pour ce site j'ai utilisé HTML, CSS, JavaScript et PHP ainsi encore d'une base de données SQL. J'ai appris à faire des cartes interactives de produits rudimentaires et autres. Ce site n'est malheureusement plus trouvable comme mon compte alwaysdata à été supprimé par l'institut.
